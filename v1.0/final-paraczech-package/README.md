# ParaCzech v1.0: Lexicon of Czech Paradigms

ParaCzech v1.0 is a collection of Czech paradigms of nouns, adjectives and verbs in phonemic and orthographic notation. They are suited for both computational and manual analysis.

The data files are encoded in `csv` files, and the metadata follows [frictionless](https://frictionlessdata.io/) standards. The dataset conforms to the [Paralex standard](https://www.paralex-standard.org)

Documentation of the ParaCzech v1.0 is stored in `docs/data_sheet.md`. It describes individual sources of annotation and how the pieces of information are stored in the files.


If you use this dataset, please cite:

- Kyjánek, L., & Bonami, O. (2026). ParaCzech v1.0: Lexicon of Czech Paradigms (Version v1.0) [Dataset]. Zenodo. [https://doi.org/10.5281/zenodo.18262654](https://doi.org/10.5281/zenodo.18262654).
